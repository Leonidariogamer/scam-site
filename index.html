How these attacks work

Different files, the same four stages. Once you can name them, they are much easier to notice.

  1. The lure

    A modpack, mod or "performance fix" arrives in a chat message, often from a hacked friend's account.

  2. The hidden file

    One file isn't what it claims to be: unlisted, wrongly named, or far too large for its job.

  3. The payload

    It runs when the game loads, then decodes or downloads the real malware.

  4. The theft

    Browser logins, Discord sessions and crypto wallets are copied out, and the attacker often keeps remote control.

Spot the odd one out

Three quick rounds based on the real samples. Pick the file that doesn't belong.

Three habits that would have stopped all of these

  1. Download mods only from the official page.CurseForge and Modrinth list every file. If a "pack" arrives as a zip in a chat, treat it as unsafe.
  2. A modpack's list should match what's inside.An extra file that isn't on the list, especially one in the mods folder, is the biggest warning sign.
  3. A friend's name isn't proof.Almost every one of these starts with a hacked account, not the attacker's own. Accounts get taken over by stealing the login token itself, not the password — which is why the account can keep messaging normally even after a password reset. Treat any unsolicited file or "join my server" link as suspicious no matter who it's from, and confirm on a different app: "did you really send me this?" Discord's own safety guidance says the same thing: a message from a known contact is not a safety signal.

Before you download anything

None of this needs special tools. A few minutes of checking catches most of these before they ever run.

  • Match it against the official listing.Find the mod or modpack's real page on CurseForge or Modrinth and compare the file name and size. A file that doesn't match what's actually listed there isn't the real one, whatever it's named.
  • Hash it, then look the hash up — don't upload the file.On Windows, run Get-FileHash in PowerShell on the file, then paste that hash into VirusTotal's search box. This checks it against everything VirusTotal has already seen without sending it anywhere. A "no results" or "0 detections" hit means the file is simply unseen, not safe — that's exactly what a freshly built scam looks like.
  • Open the archive, don't run it.A zip or jar can be browsed without extracting or launching anything — Windows File Explorer opens them directly. A real mod is mostly .class files and a manifest. A stray .exe, .bat, or .ps1, or a file structure that doesn't match the pack's own file list, is a visible warning sign.

If you already opened something

Right now

  • Disconnect from the internet and close the game and launcher.
  • From a different, clean device, change your email password first, then Discord, Steam, Microsoft and your bank.
  • Sign out of every session on every account.

Then

  • Set up two-step login again and make new backup codes.
  • Move any crypto to a brand-new wallet.
  • Back up your photos and documents, then reinstall Windows. It is the only way to be sure.
