The modpack with one extra file

  • Danger: high
  • Dropper
  • Minecraft 1.21.1 / Fabric

In one sentenceA modpack that looks like a legitimate CurseForge pack contains one unlisted mod. That mod is a downloader: when the game starts, it fetches the real malware from a file-sharing link.

Spot it, and what to do

How to spot it

  • The modpack's list names real mods, but there is one extra file in the mods folder that is not on the list.
  • The extra mod has a vague name and description, an official-sounding author ("Fabric Team"), and is only a few kilobytes. Real mods are usually megabytes.
  • It came from a chat message, not from the CurseForge or Modrinth page.
  • It arrived from a friend who "never sends files". Their account may be hacked.

If you already ran it

  • Look for a java folder inside %LOCALAPPDATA% containing services.jar. If it exists, treat the PC as infected.
  • Change passwords from a different, clean device. Email first, then Discord, Steam, Microsoft and your bank.
  • Sign out of all sessions, redo two-step login, and move any crypto to a new wallet — this one can silently swap wallet addresses you copy/paste, so double-check any crypto transfer you made while it was running.
  • Back up your files and reinstall Windows to be sure.

Technical details

For researchers: how this was analysed

The zip's manifest lists 19 genuine CurseForge projects. The extra file is overrides/mods/BetterSurvival.jar (6,337 bytes) with one class, com.example.mod.mc, in the default Fabric template package, obfuscated with ZKM (Zelix KlassMaster), which encrypts every string. Strings were recovered statically by re-implementing the decryption routine from the class's bytecode, without executing the sample, giving the chain in steps 3 to 6. A third-party sandbox run of the jar executed it as a plain Java program, so the Fabric start-up code never triggered — that's why it showed no behaviour there. A second copy of the pack, sent a day later under a new filename (BetterCraft.jar), used the same structure with freshly randomised obfuscation constants and a new, still-live download link, which is where the rest of this came from.

That link's archive (55 MB) held a portable Java runtime and the real payload, services.jar (12 MB). A separate third-party attempt to read this file with ordinary tools reportedly used up 48 GB of memory without finishing — the cause turned out to be a handful of individual program components deliberately bloated to the point that tools which try to reconstruct readable code from them run out of memory, not a huge number of components as the distributor claimed. Reading it one small piece at a time instead avoided the problem, and the whole program was turned back into readable, if still obfuscated-looking, source code (download below). Two plain-text markers inside it, a license code and a long reference number, confirm it's a licensed, bought product rather than something the distributor wrote themselves.

The second diagram above (what the second stage actually does) was confirmed by running the unmodified file on a real, disposable computer and watching it directly, after noticing it did nothing at all in a virtual machine. Its actual secrets — the exact address it reports to, names it uses to blend in — stay hidden behind their own obfuscation and were not recoverable: unlike the small first-stage mod, this one doesn't use one single trick for its text, so there's no single fix that unlocks everything.

Separately, in October 2026, an account believed to be connected to this sample's distribution was contacted directly. Some of what they said didn't hold up: they first claimed to write the malware themselves, which later information contradicts — it's a premade kit, sold through a storefront that was independently found, not original work. They also said the download link gets suspended whenever someone reports it, forcing a rebuild with a new link each time — which matches what actually happened (two separate builds, two separate links), confirming that reporting these links costs the operator a rebuild, not just one deleted file. Nothing here was obtained by running the malware, and nothing was shared with that account to help it evade detection or reporting.

Download addresses and the exact command-and-control domain are withheld here on purpose, same as throughout this writeup.
