Spot it, and what to do

How to spot it

  • The modpack's mod list is empty, yet the zip has a mods folder with a file in it.
  • The author is "Mojang". Mojang doesn't publish mods like this, and neither does a "performance" mod from a stranger.
  • The mod is about 19 MB and contains Windows login-theft code, far too heavy for a tweak.
  • The first antivirus scan said "clean". A fresh scan a day later flagged it. Always re-check.

If you already ran it

  • Check your Windows Startup folder and Task Scheduler for entries you don't recognise.
  • Look in your hosts file for Discord addresses you didn't add.
  • Change passwords from a clean device, sign out of all sessions, and reset two-step login.
  • Move crypto to a new wallet, then back up your files and reinstall Windows.

Technical details

For researchers: how it was analysed

The zip's manifest has an empty files list. overrides/mods/swap.jar declares itself as Fabric mod id perfhelper and as Main-Class, Premain-Class and Agent-Class Main, so it can run as a program, as a Java agent, or as a mod through SwapFabricMod or SwapForgeMod.

About 2,900 of its 2,966 entries are bundled libraries. The attacker code is a set of root-level classes that read Chromium and Firefox data (including Chrome's app-bound encryption keys), Discord tokens and wallet extensions. It has an embedded HTTP server with a command interface, edits the hosts file to block Discord QR login, installs a startup shortcut and scheduled task, and impersonates Winlogon to get a SYSTEM token. Some strings are in Turkish.

It shares a set of custom Discord badge images with "The fake Fabric API", which suggests a common builder or kit. That is a lead, not proof of a single author. The two use different code, so this is not a repackaged copy.
